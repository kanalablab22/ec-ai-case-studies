在庫自動監視
& 入荷分析

売れ筋商品の在庫を1日に複数回チェックし、残りわずかになったら自動でSlackに通知。 さらにAIが社内の入荷連絡を探し出して、「次はいつ入るのか」の判断材料まで添えてくれる仕組みを実現しました。

カテゴリ 在庫監視・AI分析
技術スタック Python / launchd / Slack API
チェック頻度 1日5回 自動実行
対応店舗 複数店舗対応
課題と解決策

😰 Before（課題）

  • 売れ筋商品の在庫を、担当者が思い出したときに手動で見に行くしかなかった
  • 気づいたときには在庫切れ寸前、機会損失につながることも
  • 「次はいつ入荷するんだっけ？」を毎回Slackやメールを遡って確認していた

🎉 After（解決）

  • 1日5回、自動で在庫をチェック。残りわずかになった瞬間にSlackへアラート
  • 在庫が復活したときも「復活しました！」と自動でお知らせ
  • AIが社内の入荷連絡を自動で探し、通知にそのまま添えてくれる

1日5回の自動チェック

launchdで毎日9時〜21時に自動実行。しきい値を下回った商品だけ通知します。

技術的なポイント

🎯 SKU単位で在庫を把握

商品ページの中に埋め込まれた在庫データを読み取り、カラー・サイズごとの残数を正確に取得。「グレーだけ在庫切れ」といった細かい状況もきちんと検知します。

Python + HTML解析

🔔 通知しすぎないブレーキ

同じ在庫数のときは再通知しない仕組みを内蔵。「毎回同じアラートが来てうるさい」を防ぎ、在庫が変化したときや復活したときだけお知らせします。

状態管理（state.json）

🤖 AIによる入荷分析

アラート時に社内チャットから「入荷」「納品」「再入荷」などの連絡を自動検索。商品名が省かれた投稿も拾い上げ、次回入荷の判断材料を通知に添えます。

Slack Search API

🔒 認証情報は安全に保管

通知用のURLやトークンはコードに直書きせず、macOSのキーチェーン（パスワード金庫のような仕組み）から読み取り。情報漏えいのリスクを抑えています。

💡 「一時停止リスト」で柔軟に運用

販売終了やリニューアル中の商品は、除外リストに名前を書くだけで監視を一時停止できます。コードをいじる必要はありません。監視対象の追加・除外も設定ファイルで手軽に管理でき、店舗や商品が増えても同じ仕組みをそのまま横展開できます。
