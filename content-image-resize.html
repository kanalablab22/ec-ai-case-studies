コンテンツ画像リサイズ

楽天のコンテンツページに載せる画像を、規定の横幅にブラウザ上でまとめてリサイズ。 ドラッグ＆ドロップするだけで、縦横比を保ったまま最適サイズにピタッと整えてくれる、 インストール不要のシンプルなツールです。

カテゴリ 画像加工・作業効率化
技術スタック HTML / Canvas API / JavaScript
出力サイズ 1600 × 900px（JPEG）
動作環境 ブラウザ単体・完全ローカル
課題と解決策

😰 Before（課題）

  • コンテンツページ用の画像を、毎回画像編集ソフトで規定幅にリサイズしていた
  • 縦横比を崩さないよう手作業でサイズ計算し、余白を足す作業が地味に面倒
  • ファイル名も楽天RMSのルール（半角英数字・文字数制限）に合わせて手直しが必要
  • 枚数が多いと1枚ずつ書き出すのに時間がかかっていた

🎉 After（解決）

  • ブラウザにドラッグ＆ドロップするだけで、規定サイズに自動リサイズ
  • 縦横比はキープしたまま、足りない部分は余白で自動調整（色も選べる）
  • ファイル名もRMSルールに沿った形へ自動で整えてから書き出し
  • 複数枚をまとめて一括ダウンロードできるので、大量画像もあっという間

技術的なポイント

🌐 インストール不要のブラウザ完結

HTMLファイル1枚をブラウザで開くだけで動く、シンプルなツールです。画像はどこにも送信されず、すべてお使いのPCの中だけで処理されるので、安心して使えます。

HTML + Canvas API

📐 縦横比キープ＋余白の自動調整

元画像の比率を崩さずに規定サイズの枠へ配置。足りない余白は自動で塗りつぶし、色は白・ベージュ・黒からワンタッチで選べます。ズームや表示位置も後から微調整できます。

アスペクト比フィット

🏷️ RMSルールに沿ったファイル名

楽天RMSの画像ファイル名ルール（半角英数字・文字数制限）に合わせて、ファイル名を自動で整えてから書き出します。アップロード時のエラーを未然に防げます。

ファイル名自動整形

✏️ 気になる部分を消せる補正機能

画像の右下などを、近くの部分をコピーして自然になじませる補正機能つき。ドラッグで範囲を選ぶだけで、余計な要素をさっと目立たなくできます。

💻 Windows環境でもそのまま使えます

HTMLファイル1枚だけで動くツールなので、macOSでもWindowsでも、Chromeなどのブラウザで開くだけで同じように使えます。特別なインストールや設定は一切不要で、画像はすべて端末内で処理されるため、ネット接続がなくても動作します。
