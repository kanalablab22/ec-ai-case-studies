日次売上レポート
自動配信

データウェアハウス（BigQuery）に蓄積された売上データを毎朝自動で集計し、 店舗別の売上サマリーをSlackへ自動配信する仕組み。 朝いちばんの数字チェックが、通知を開くだけで完結するようになりました。

カテゴリ データ集計・自動通知
技術スタック Python / BigQuery / Slack Webhook
実行タイミング 毎営業日 定時に自動実行
対応店舗 複数店舗をまとめて配信
課題と解決策

😰 Before（課題）

  • 毎朝、店舗ごとに管理画面へログインして前日の数字を確認していた
  • 売上・利益・予算に対する進捗を手作業で集計・転記するのが手間だった
  • 複数店舗分をまとめて見たいのに、店舗の数だけ画面を行き来する必要があった

🎉 After（解決）

  • 毎朝、複数店舗の売上サマリーがSlackに1通で自動で届く
  • 売上・貢献利益・予算比まで計算済みで、開くだけで進捗がわかる
  • 土日祝は自動でお休み。稼働日だけ、必要なときに届く

技術的なポイント

🏪 複数店舗を1通に集約

複数の店舗の数字を1つのメッセージにまとめて配信。店舗ごとに画面を開かなくても、Slackを見るだけで全体の状況が一目で把握できます。

Slack Webhook

📅 土日祝を自動でスキップ

祝日判定を組み込み、土日祝は配信をお休み。稼働日だけ通知が届くので、通知が埋もれず、必要なときだけ確認できます。

祝日カレンダー判定

🧮 予算比は日割りベースで算出

月間予算をその日までの日数で日割りし、実績と比較。「今月このペースで予算に対してどうか」を、毎朝ひと目で確認できます。

予算ペース計算

🔒 認証情報は安全に保管

接続に必要な認証情報はコードやファイルに平文で書かず、OS標準の安全な保管領域から読み込む方式を採用。公開・共有しても情報が漏れない設計です。

💻 他店舗・他指標にも展開可能

配信する店舗や指標はカスタマイズ可能で、店舗が増えても同じ仕組みでそのまま拡張できます。配信先はSlackに限らず、チームで使っているチャットツールに合わせて差し替えることもできます。数字を「取りに行く」から「毎朝届く」へ切り替える、シンプルながら効果の大きい自動化です。
