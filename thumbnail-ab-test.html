ANALYSIS

サムネイル変更
効果測定

サムネイル画像を変更した前後で、クリック率・アクセス人数・転換率・売上の変化を自動で前後比較。 サムネ改善の効果を数字で裏づけます。「なんとなく良くなった気がする」を、はっきりした数値に変える仕組みです。

カテゴリ 効果測定・データ分析
技術スタック Python / BigQuery / Google Sheets API
実行頻度 毎朝 自動実行
判定タイミング 14日後・30日後の2段階
課題と解決策

😰 Before（課題）

  • サムネを変えても「良くなった気がする」で終わり、効果を数字で確認できていなかった
  • 売上が動いても、それがサムネのおかげなのかセールや季節要因なのか切り分けられない
  • 変更前後のデータを手作業で集計・比較するのが面倒で、つい後回しになっていた

🎉 After（解決）

  • 変更前と変更後の指標を自動で前後比較。サムネ改善の効果がひと目でわかる
  • 店舗全体のトレンドで補正し、セールや季節のノイズを除いた「サムネそのものの効果」を判定
  • 14日後・30日後に自動で判定してSlackに通知。維持か戻すかの判断材料が勝手に届く

仕組みのポイント

⚖️ 店舗全体トレンドで補正

売上が伸びてもセールや季節のおかげかもしれません。そこで同じ期間の店舗全体の伸び率と比べ、「サムネそのものの効果」だけを取り出して判定します。だから数字を過大評価しません。

トレンド補正ロジック

🏷️ セール期間を除いて判定

前後の期間にスーパーSALEが入ると割引ブーストで効果を見誤ります。セール日を除いた通常価格ベースで比較し、日数がズレる分は1日あたりに換算してフェアに比べます。

通常価格ベース補正

📣 広告費の増減をチェック

広告費が前後で大きく動いていると、それがサムネ効果と混ざってしまいます。広告費が±30%以上変わっていた場合は自動で警告メモを付け、判断を誤らないようにしています。

±30% 警告フラグ

🗓️ 14日後・30日後の2段階判定

14日後は経過観察としてまず様子見。30日後にあらためて数字を見て「維持・微調整・元に戻す」を決めます。焦って早合点しない、落ち着いた判断ができる設計です。

💡 「感覚」から「数字」への転換

サムネ変更はクリック率（＝アクセス人数）とサムネと中身の一致度（＝転換率）に効く施策です。この仕組みは、その2つの観点を軸に4指標を自動で前後比較し、店舗全体トレンドで補正した「本当の効果」を数字で示します。人手の集計をなくし、判断の根拠を毎回そろえられるのが一番の価値です。数値はすべてサンプルのイメージ値です。
