画像圧縮ツール

楽天RMSの画像容量制限に対応するため、画像をブラウザ上でドラッグ＆ドロップするだけで自動的に軽量化。 画質を保ちつつファイルサイズを削減し、面倒な圧縮作業をワンステップで終わらせる仕組みを実現しました。

カテゴリ 画像最適化・作業効率化
技術スタック HTML / JavaScript / Canvas API
動作環境 ブラウザ内で完結（インストール不要）
対応形式 JPG / PNG（複数枚まとめて）
課題と解決策

😰 Before（課題）

  • 楽天RMSには画像1枚あたりの容量制限があり、大きい画像はアップロードできなかった
  • そのたびに別の圧縮アプリやWebサービスに画像をアップして変換する手間が発生
  • 1枚ずつ処理するのが面倒で、何十枚もあると時間がかかっていた

🎉 After（解決）

  • 画像をドラッグ＆ドロップするだけで、目標サイズ以下に自動で軽量化
  • 複数枚をまとめて放り込めば、一気に圧縮してくれる
  • 処理はすべてブラウザ内で完結。画像はどこにもアップロードされず安心

技術的なポイント

🎨 Canvas APIで画質を保つ圧縮

ブラウザ標準のCanvas APIで画像を再描画し、JPEGの品質を少しずつ下げながら目標サイズに近づけます。見た目の劣化を抑えつつ、しっかり容量を削減できるのがポイントです。

Canvas toBlob()

📐 品質調整とリサイズの2段構え

品質を下げても目標サイズに届かない場合は、画像を段階的に縮小して再圧縮。大きすぎる画像でも確実に容量制限内に収まるよう工夫しています。

段階的リサイズ

🔄 透過なしPNGはJPGへ自動変換

透明部分のないPNGは、そのままだと縮みにくいため自動でJPGに変換。透過が必要な画像はPNGのまま保持するので、用途に応じて最適な形式を選びます。

アルファ値判定

🔒 アップロード一切なしで安全

画像の処理はすべて自分のブラウザの中だけで完結します。外部のサーバーに画像を送らないので、商品画像の情報が外に漏れる心配がありません。

💻 インストール不要でどの環境でも使える

このツールはHTMLファイル1枚だけで動くので、ソフトのインストールは一切不要です。ファイルをダブルクリックしてブラウザで開くだけ。macOSでもWindowsでも同じように使え、Canvas APIは主要なブラウザにすべて標準搭載されているため、環境を選ばず動作します。
