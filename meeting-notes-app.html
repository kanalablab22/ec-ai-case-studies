AI議事録アプリ
文字起こし & 自動要約

会議の音声をアップロードするだけで、自動で文字起こし→AI要約→議事録を生成するWebアプリ。 要約・決定事項・ToDoまで自動で整理し、Googleドキュメントへの保存やPDF出力までワンストップで完結します。

カテゴリ AI（音声認識・要約）
技術スタック Next.js / Groq Whisper / Gemini
対応モード 対面 / オンライン
保存先 Google Docs / PDF
課題と解決策

😰 Before（課題）

  • 会議のたびに手作業で議事録を書き起こしていて、時間がかかっていた
  • 外部ツールの利用回数に制限があり、会議が多い週は残り回数が気になっていた
  • 対面用・オンライン用でツールが分かれ、議事録の保存場所がバラバラだった

🎉 After（解決）

  • 音声をアップロード（または録音）するだけで、議事録が自動で完成
  • 要約・決定事項・アクションアイテムまでAIがきれいに整理
  • 1つのアプリに統一。Google Docsに自動保存され、どの端末からも見られる

技術的なポイント

🎧 2つの文字起こしモード

対面会議はブラウザ内蔵の音声認識でその場で文字起こし、オンライン会議は音声ファイルを高精度な文字起こしエンジンに渡して処理。会議のスタイルに合わせて自動で使い分けます。

Web Speech API + Whisper

🤖 生成AIで議事録化

文字起こしした会話を生成AIに渡し、要約・議論の詳細・決定事項・アクションアイテムに構造化。だらだらした発言も、読みやすい議事録の形に整えてくれます。

Gemini API

📚 単語帳で表記ゆれ対策

よく使うブランド名・商品名・社名などを登録しておくと、文字起こし・要約の段階で正しい表記に自動でそろえます。固有名詞の聞き間違いを減らせる工夫です。

用語辞書

📄 Google Docs自動保存

できあがった議事録はGoogleドキュメントに自動保存。履歴がずっと残り、どの端末からでも見返せます。その場での編集やPDFダウンロードにも対応しています。

🔒 安心して使える設計

Googleアカウントでのログインに対応し、議事録は自分のGoogleドキュメントに保存されます。APIキーなどの秘密情報は環境変数で分離管理し、画面や出力には一切出さない設計です。今日の会議一覧から選ぶだけで録音を始められるので、非エンジニアの方でも迷わず使えます。
