修正指示ツール
（LPレビュー共有ボード）

デザイナーから届いた長いLP画像をそのまま貼り付けて、直したい場所を囲んでコメントを残せる共有ボードを自社開発。 URLを送るだけで社内・社外の相手も書き込めて、外部サービスの「無料版は7日で消える」「大きい画像は弾かれる」という悩みを両方解消しました。

カテゴリ 修正指示・レビュー共有
技術スタック Cloudflare Pages / D1 / Python
共有方法 URLを送るだけ（ログイン不要）
運用コスト 無料枠のみ・0円
課題と解決策

😰 Before（課題）

  • 使っていた外部の修正指示サービスは、無料版だと7日でページが消えてしまう
  • 20MBを超える画像は登録できず、デザイナーから届く長いLPを手で切り分けてから貼る必要があった
  • 相手に登録してもらう前提だと、社外の協力先に気軽に頼みづらい
  • やりとりがメールやチャットに散らばり、「どの場所の話か」が伝わりにくい

🎉 After（解決）

  • 長いLPをそのままドラッグ＆ドロップ。ブラウザ内で自動的に分割・軽量化してアップロード
  • 発行されたURLを送るだけ。相手もログイン不要でその場でコメントを書き込める
  • 必要なときだけパスコードを付けられるので、社外共有も安心
  • 直したい場所を四角で囲んでコメントするので、「どこの話か」が一目で伝わる

技術的なポイント

✂️ 画像の分割はブラウザの中で

アップロードの前に、ブラウザ側で画像を一定の高さごとに切り分けて1枚ずつ軽量化します。サーバーに大きなファイルを送らないので、外部サービスのサイズ制限に悩まされず、長いLPもそのまま扱えます。表示側では継ぎ目なく縦につながって見えます。

クライアント側で前処理

🌐 URLキャプチャにも対応

手元の画像だけでなく、公開ページのURLを渡して丸ごとキャプチャして取り込むこともできます。ブラウザだけでは撮れない縦長ページも扱えるように、Mac・Windowsどちらでも動く小さなツールを添えました。

Mac / Windows 両対応

🔓 ログイン不要 ＋ 任意のパスコード

相手にアカウントを作ってもらう必要がないので、社外の協力先にもURL1本で頼めます。人に見られたくない内容のときはパスコードを付けられるので、手軽さと安心のバランスを取っています。

社内・社外どちらもOK

🧹 30日で自動お掃除・運用コスト0円

保管はクラウドの無料枠だけで完結し、カード登録も不要。古いボードはアクセスのついでに自動で片付けられるので、放っておいても容量が膨らみません。「7日で消える」制約からも解放されました。
