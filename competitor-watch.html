MONITORING

競合ウォッチ
自動検知

気になる競合商品の価格・サムネイル・レビュー・クーポンを毎朝そっと見に行き、 前回から変化があった項目だけをMac通知やSlack DMでお知らせ。 「いつの間にか値下げされてた」を、もう見逃しません。

カテゴリ 競合モニタリング
技術スタック Python / launchd / Slack API
実行頻度 毎朝10:00 自動実行
見張る項目 価格・サムネ・レビュー・クーポン
課題と解決策

😰 Before（課題）

  • 競合商品の値下げやクーポンに気づくのが遅れ、対応が後手に回っていた
  • 複数の競合ページを毎日手作業で開いて見比べるのは時間も気力も消耗する
  • 「サムネが変わった」「レビューが急に増えた」といった小さな変化はどうしても見落としがち

🎉 After（解決）

  • 毎朝ツールが自動で競合ページを巡回し、変化があった時だけ通知が届く
  • 価格・サムネ・レビュー・クーポンの4項目を一度にまとめて見張れる
  • 変化がなければ静かにしているので、通知が来たら「動きがあった」とすぐ分かる

毎朝の自動巡回

launchdで毎朝10:00に自動実行。前回の状態と見比べて、変化があった項目だけを検知します。

競合ウォッチ 👀
🔔 競合に動きあり：競合商品A

💴 価格が変わりました
　4,980円 → 3,980円（▼値下げ 1,000円）
📝 レビュー件数が変わりました
　128件 → 134件（+6件）
🎫 クーポンが付きました：500円OFF

変化だけをSlack DMで通知

どこがどう変わったのかを人が読みやすい文章で通知。Slack未設定ならMac通知に自動で切り替わります。

仕組み
STEP 01
📋

競合リスト読込

STEP 02
🌐

ページ取得・解析

STEP 03
🔍

前回と差分検知

保存済みの前回状態と見比べて変化を発見

STEP 04
🔔

変化だけ通知

動きがあった項目をSlack/Mac通知でお知らせ

技術的なポイント

🔍 前回スナップショットと差分比較

各商品の状態をローカルに保存しておき、次回チェック時に見比べます。変化があった項目だけを「4,980円 → 3,980円」のように人が読みやすい文章に組み立てて通知します。

差分検知ロジック

🕊️ サイトに優しいアクセス設計

ページは読み取るだけで、書き込みや送信は一切しません。商品ごとに間隔をあけて取得し、相手のサーバーに負荷をかけない優しい巡回を心がけています。

GET only / 取得間隔

🔔 通知の自動フォールバック

Slack DMが設定されていればそこへ、未設定ならMacの通知センターへ、と自動で切り替え。どの経路でも通知内容はログに必ず残るので、あとから見返せます。

Slack API + Mac通知

⏰ 眠っていても取りこぼさない自動実行

launchdで毎朝決まった時刻に自動実行。その時刻にMacが眠っていても、次に開いたタイミングで自動的に1回実行してくれるので、チェック漏れが起きません。

💻 Windows環境でも対応可能

本事例ではmacOSのlaunchdで自動実行していますが、Windowsでもタスクスケジューラを使えば同じ仕組みを構築できます。ページの取得・差分検知・Slack通知の部分はOSを問わずそのまま利用できるので、環境に合わせて自動実行の仕組みだけ差し替えればOKです。
