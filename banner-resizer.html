楽天バナー
自動リサイズ

1枚のバナー画像から、楽天の各掲載枠サイズへワンクリックで自動リサイズ。 Downloadsフォルダを常時監視し、画像が入ると自動でリサイズ画面が立ち上がる仕組みを実現しました。

カテゴリ 画像処理・作業自動化
技術スタック Canvas API / Python / launchd
対応枠 1440×280 / 1080×210 / 1600×900 ほか
対応OS macOS / Windows
課題と解決策

😰 Before（課題）

  • 1枚のバナーを掲載枠ごとに、画像編集ソフトで何度も手作業リサイズ
  • 枠に合わせた余白の追加や、被写体の位置調整がサイズ違いのたびに発生
  • 楽天RMSのファイルサイズ上限（1950KB以下）を超えないよう毎回チェックが必要

🎉 After（解決）

  • 1枚の元画像から、各掲載枠サイズへワンクリックで一括書き出し
  • ドラッグ＆ズームで位置調整、余白色も選べて仕上がりを自分でコントロール
  • 指定KB以下へ自動圧縮。まとめてZIP保存で、そのままRMSにアップできる状態に

技術的なポイント

🖥️ ブラウザだけで画像処理

リサイズも圧縮もブラウザのCanvas機能だけで完結。専用ソフトのインストール不要で、画像はPCの外に一切送られません。手動モードなら常駐ツールが止まっていても使えます。

Canvas API

👀 Downloads監視の常駐ウォッチャー

PC内だけで動く小さなサーバーがDownloadsフォルダを2秒おきに監視。対象の画像が入るとリサイズ画面を自動で開き、その画像を読み込ませます。外部からはアクセスできません。

Python http.server

🎯 ファイル名で賢く判定

生成AIらしいファイル名だけに反応するよう調整。スクリーンショットやツール自身の書き出しには反応しないので、余計な画面が開く心配がありません。

パターンマッチ

🔁 ログイン時に自動起動

ウォッチャーはPC起動時に自動でスタンバイ。macOSはログイン項目、Windowsはスタートアップに登録するだけ。普段は存在を意識せず使えます。

💻 macOS / Windows 両対応

本ツールはmacOSとWindowsのどちらでも使えます。macOSはログイン項目、Windowsはスタートアップに起動ファイルを登録するだけで、Downloads監視が常駐します。リサイズ画面はブラウザで動くため、OSを問わずそのまま同じ操作感で利用できます。画像はすべてPC内だけで処理され、外部に送信されることはありません。
