滞在時間カルテ
（AIの読み解き付き）

新作バッグの滞在時間や直帰の動きを、日ごとに追いかけるカルテです。データの取得からグラフの更新、AIによる読み解きの文章まで、毎日自動で行われます。

カテゴリアクセス分析・AI要約
技術スタックPython / GitHub / Claude
取得1日3回・直近3日を取り直し
読み解き1日2回 AIが執筆
課題と解決策

😰 Before（課題）

  • 滞在時間を見るには、毎回管理画面を開いて商品を探す必要があった
  • 管理画面は50件までしか表示せず、全商品を並べて見られなかった
  • 期間でまとめて見ると、イベントの前後で起きた変化が平均に埋もれた
  • 数字を見ても、何が起きたのかを言葉にするのに時間がかかった

🎉 After（解決）

  • 新作3型の滞在時間・直帰を、日ごとの推移で見られる
  • 全商品のデータを毎日保存しているので、あとから別の商品も追える
  • AIが前日からの変化を2〜4枚のカードで読み解いてくれる
  • 集計が遅れた日も、直近3日の取り直しで自動的に埋まる

技術的なポイント

🔍 画面の裏にある全商品のデータを使う

管理画面は50件までしか出しませんが、その裏で動いている仕組みからは全商品のデータが取れることが分かりました。お気に入り数の記録で使っていた取得をそのまま活かし、捨てていた項目まで保存しています。

既存の取得を活かす

🩹 集計の遅れは自分で埋め合わせる

前日分のデータは翌日のお昼前まで出そろわないことを実測で確かめました。1日3回、直近3日分を取り直して上書きするので、早い時間に空振りした日も夕方には正しい値に直ります。

自己修復する取得

🔗 社内とクラウドをGitHubでつなぐ

クラウドで動くAIは社内のサーバーに直接届きません。社内のサーバーがデータをGitHubに置き、クラウドのAIがそれを読んで読み解きを書き、ページを公開する二段構えにしました。

届かない場所をつなぐ

🎨 色だけで系列を分けない

最初は似た緑系の色を2つ使っていて、見分けにくいと指摘を受けました。色の系統をはっきり分けたうえで点の形も変え、凡例にも同じ形を出しています。
