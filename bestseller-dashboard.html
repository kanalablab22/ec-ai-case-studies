売れ筋ダッシュボード
自動更新

市場の売れ筋商品データを定期的に取得してJSONに整形し、Webダッシュボードで自動表示。 いつダッシュボードを開いても、最新の売れ筋トレンドが一目で確認できる仕組みを作りました。

カテゴリ データ取得・可視化
技術スタック Python / Playwright / JSON / GitHub / Netlify
更新頻度 定期自動更新
対象データ 市場全体の売れ筋ランキング
課題と解決策

😰 Before（課題）

  • 売れ筋データを見るたびに分析サービスに毎回ログインして操作する必要があった
  • カテゴリごとにランキングを開いて手作業でコピー、集計するのが手間だった
  • 最新データがいつ更新されたのか分からず、見に行くタイミングを逃しがちだった

🎉 After（解決）

  • ダッシュボードのURLを開くだけで、いつでも最新の売れ筋ランキングが見られる
  • データ取得からJSON化・表示までが全自動。手作業のコピペはゼロに
  • 裏側で定期的にデータが差し替わるので、常に新鮮なランキングが並ぶ

技術的なポイント

🤖 データ取得の自動化

外部の市場分析データから、カテゴリ別の売れ筋ランキングをPlaywright（ブラウザ自動操作の仕組み）で自動取得。手作業のコピペを完全になくしました。

Python + Playwright

📝 表示に最適なJSON設計

取得した生データを、そのままダッシュボードで描画できる軽量なJSON形式に整形。商品名・価格・販売数など、必要な項目だけをきれいに並べています。

data.json

☁️ 更新すれば即反映

整形したJSONをGitHubへ自動アップロードすると、Netlify経由でWebダッシュボードに自動反映。サーバー管理なしで、常に最新データを配信できます。

GitHub + Netlify

🖼 共有用プレビュー画像

ダッシュボードとは別に、ランキングを1枚の画像に書き出す補助機能も用意。チャットにそのまま貼れるので、チームへの共有がぐっとラクになります。

💻 Windows環境でも展開可能

本事例ではmacOSで運用していますが、Windowsでも同じ仕組みを構築できます。データ取得部分はPython + Playwrightで動くのでOSを問わず、JSON化・GitHub連携・ダッシュボード表示の部分はそのまま使えます。定期実行はmacOSならlaunchd、Windowsならタスクスケジューラで設定します。
